# 경쟁형 적금 웹 서비스
랭킹·보상 기반 금융 웹 서비스 (팀 프로젝트)

---

## 프로젝트 개요

본 프로젝트는 사용자의 저축 동기를 강화하기 위해  
랭킹 시스템과 보상 구조를 결합한 경쟁형 적금 웹 서비스입니다.

정기 적금 상품에 가입한 사용자는 일정 주기로 납입을 진행하며 순위를 경쟁하고,  
만기 시 이자 또는 골든볼(보너스 보상) 중 하나를 선택할 수 있습니다.

금융 서비스의 핵심 요소인 정기 결제, 보안, 만기 처리, 데이터 무결성을  
실제 서비스 수준으로 구현하는 것을 목표로 개발했습니다.

---

## 프로젝트 목표

- 실제 은행 적금 서비스의 구조와 사용자 흐름 분석
- 정기 결제, 만기 처리, 중도 해지 등 금융 로직 구현
- 랭킹 및 보상 시스템을 통한 사용자 참여 유도
- Spring Boot 기반 백엔드 중심 웹 서비스 설계 역량 강화

---

## 벤치마킹

| 서비스 유형 | 벤치마킹 요소 | 반영 내용 |
|------------|--------------|----------|
| 은행 적금 서비스 | 정기 납입, 만기 이자 지급 | 자동이체 기반 적금 로직 |
| 경쟁형 챌린지 서비스 | 랭킹 시스템 | 매일 자정 랭킹 갱신 |
| 금융 이벤트 서비스 | 보상 구조 | 골든볼(보너스) 시스템 |

기존 적금 서비스의 안정성과 경쟁형 서비스의 참여 요소를 결합하여  
단순 저축을 넘어 게임적 요소가 있는 금융 서비스로 설계했습니다.

## 핵심 기능

### 적금 시스템
- 기간별 적금 상품 (1개월 / 3개월 / 6개월 / 1년)
- 정기 자동이체 (일 / 주 / 월 단위)
- 중도 해지 시 수수료 차감 환급
- 만기 시 이자 또는 골든볼 선택
- 매일 00시 기준 랭킹 자동 갱신

### 결제 시스템
- Toss Payments API 연동
- 카드 결제 / 계좌 이체
- 자동 결제 설정
- 결제 보안 처리

### 커뮤니티
- 공지 게시판 및 Q&A
- 랭킹 및 당첨자 공지
- 사용자 간 정보 공유

### 관리자 기능
- 회원 관리
- 적금 상품 등록 / 수정 / 삭제
- 상품별 매출 및 당첨자 관리
- 권한 분리 (ROLE_USER / ROLE_ADMIN)

## 개발 후기

실제 금융 서비스와 유사한 구조를 구현하며  
정기 결제, 보안, 데이터 정합성의 중요성을 체감할 수 있었습니다.

백엔드 개발 역량을 강화할 수 있었습니다.
